## 📄 Descrição do portfólio

Site pessoal responsivo que apresenta minha trajetória, habilidades técnicas, atividades acadêmicas e informações de contato. O design foi construído com uma identidade visual própria criada no **Adobe Color**, usando a paleta: cinza escuro `#343434`, laranja âmbar `#FFAA00` e branco `#FFFFFF`.

O site conta com animações CSS, efeitos de hover elaborados, gradiente animado no hero, textura de pontos no fundo e logos SVG originais das redes sociais — tudo feito com HTML e CSS puro, sem frameworks.

---

## ⚙️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 puro (Flexbox, Grid, Media Queries, `@keyframes`, `transition`, `transform`)
- JavaScript vanilla (menu mobile, animação de entrada ao rolar)
- Google Fonts (Poppins)
- Adobe Color (criação da paleta de cores)

---

## 🚧 Principais desafios encontrados

- **Estilização com CSS** — o maior desafio foi entender como encadear propriedades como `transition`, `transform` e `@keyframes` para criar animações suaves sem comprometer a performance
- **Gradiente animado** — fazer o `background-size` e o `animation` trabalharem juntos para o efeito de "respiração" no hero exigiu bastante teste
- **Responsividade** — adaptar o layout para diferentes tamanhos de tela sem usar frameworks, apenas com `media queries` e `flexbox`
- **SVG das logos** — entender a estrutura de `path` e `viewBox` para incorporar as logos originais do Gmail, LinkedIn e GitHub diretamente no HTML
- **GitHub Pages** — configurar o branch correto (`master`) e resolver conflitos de histórico entre branches durante o deploy
